# snow-freshwater-fluxes: 

Code for calculating lateral freshwater fluxes from snow on sea ice in Fram Strait and Davis Strait

For generating plots, use freshwater_fluxes.ipynb (freshwater_fluxes.py in repository)

Numerical values of calculated fluxes are in the calculated_fluxes subdirectory (refer to "Output data" section below for description)

## Quick start

- Extract gate_snow_depths_for_fw_calc.zip to main directory
- Extract gate_averages.zip and place in gate_averages subdirectory
- Install required Python dependencies using conda with the provided environment.yaml file
- (Optional) use Jupytext to convert freshwater_fluxes.py to a Jupyter notebook (freshwater_fluxes.ipynb)
- Run freshwater_fluxes.ipynb (or freshwater_fluxes.py)

## Prerequisites

Many scripts in this repository are Jupyter notebooks converted to .py scripts via Jupytext. These scripts should be runnable as .py files but may have unexpected behaviour (e.g. generating excess figures). 

Gate shapefiles are provided in gates-buffer-50km.zip; need to be unzipped and placed in shapefiles subdirectory for grid-aggregation scripts to run (though not needed for final plotting script).

The conda environment used is provided in environment.yaml; the provided environment is functional but is not a minimal install.

Data processing scripts may need adjustments for file path locations (especially for loading raw data)

## Data used

Sea ice fluxes from the RADARSAT Constellation Mission and Sentinel-1 (Howell et al., 2022): https://catalogue.ec.gc.ca/geonetwork/srv/api/records/09ab22c4-e211-4d23-afe6-9e7aa6831c62

Ice volume flux calculated in the above using Landy et al. (2022) year-round sea ice thickness data: https://data.bas.ac.uk/full-record.php?id=GB/NERC/BAS/PDC/01613

Snow datasets used (article references + dataset doi):
- NESOSIM: NASA Eulerian Snow On Sea Ice Model, v1.1 (Petty et al., 2018): https://zenodo.org/records/18273881
- SnowModel-LG: Lagrangian Snow Distributions for Sea Ice Applications, version 1 (Liston et al., 2020; Stroeve et al., 2020): https://nsidc.org/data/nsidc-0758/versions/1
- 5VLSTM: 25 km resolution snow depth on Arctic sea ice dataset (2012-2020) (Li et al., 2022): https://data.tpdc.ac.cn/zh-hans/data/8b4b5f67-ee01-45ee-96a6-db8f712a2e0c
- LEGOS: Multi-frequency altimetry snow depth product over Arctic sea ice (Carret et al., 2025): https://doi.org/10.5281/zenodo.14000765
- NaRRS: Nadir Radiometer and Radar Synergy for Arctic Snow Depth and Sea Ice Thickness Retrieval (Nelson et al., 2026): https://doi.org/10.5281/zenodo.17942492

Sea ice age:
- EASE-Grid Sea Ice Age, Version 4 (Tschudi et al., 2019): https://doi.org/10.5067/UTAV7490FEPB

Snow salinity:
- From observational data from Nandan et al. (2017): https://doi.org/10.1002/2017GL074506

Full references for citations are included in the References section below.

## Input files for plotting

For freshwater_fluxes.ipynb, the following input files are provided:

Calculated ice area and volume fluxes over the gates from RCM/Sentinel-1:
- fram-strait-ice-fluxes-v2.csv
- davis-strait-ice-fluxes-v2.csv

Gate-averaged snow depths from the snow products listed above:
- gate_snow_depths_for_fw_calc.zip; extract and place in the main directory to be accessed by freshwater_fluxes.ipynb

Gate-averaged snow freshwater as water-equivalent heights:
- gate_averages.zip; extract and keep in gate_averages subdirectory to be accessed by freshwater_fluxes.ipynb

Sea ice salinity and density calculated based on sea ice age:
- monthly_sea_ice_density_from_age.csv
- monthly_sea_ice_salinity_from_age.csv

Uncertainties in sea ice freshwater fluxes for Fram Strait and Davis Strait (km^3/month):
- fram_monthly_ice_fwf_uncert.csv

## Full processing workflow:

For processing files from scratch (i.e. using downloaded snow data), the process is as follows

1. Preprocess snow data (if needed; e.g. regridding for AMSR2/5VLSTM and S3/NaRRS)
2. Regrid sea ice age (regrid_sea_ice_age.ipynb)
3. Calculate snow salinity (snow_salinity_calculation.ipynb)
4. Calculate sea ice density and salinity (calc_ice_density_salinity_gate_avg.ipynb)
5. Clip to gate shapefiles (batch_clip_to_shapefile_intermediate.ipynb)
6. Calculate freshwater fluxes from clipped files (calc_freshwater_fluxes_from_clipped_data.ipynb)
7. Plot calculated freshwater fluxes (freshwater_fluxes.ipynb)

### Preprocess snow data

- Regridding for AMSR2/5VLSTM (regridding onto SnowModel-LG grid; needs regridding onto a common grid due to differences in day-to-day alignment): consolidate_pmw_tif_files.ipynb
- Monthly aggregation for S3/NaRRS swath data: monthly_aggregate_s3_data.py

### Regrid sea ice age

Regrid sea ice age to the respective grid for each snow product grid used: regrid_sea_ice_age.ipynb

### Calculate snow salinity

- Once snow datasets are preprocessed, calculate snow salinity using snow_salinity_calculation.ipynb
- Uses values stored in snow_salinity_by_height_for_processing.csv based on Nandan et al. (2017)

### Calculate sea ice salinity
- Ice-age-dependent sea ice density based on Landy et al. (2022), salinity based on Vancoppenolle et al. (2005)
- Script to run: calc_ice_density_salinity_gate_avg.ipynb
- Creates files monthly_sea_ice_density_from_age.csv, monthly_sea_ice_salinity_from_age.csv

### Clip data to flux gate shapefiles
- Flux gate shapefiles stored in shapefiles subdirectory (extract from gates-buffer-50km.zip and place in shapefiles subdirectory)
- Script to run: batch_clip_to_shapefile_intermediate.ipynb
- Uses input from snow_salinity_calculation.ipynb, regrid_sea_ice_age.ipynb, and consolidate_pmw_tif_files.ipynb
- Saves clipped data files in shapefile_clipped_data directory
- Separate script from gate averaging script to reduce memory use and facilitate recalculation of gate-average values
- Script needs to be edited every time a new snow dataset is added
- To aggregate snow thickness data over flux gates: aggregate-snow-over-flux-gates.ipynb

### Calculate freshwater fluxes
- calc_freshwater_fluxes_from_clipped_data.ipynb
- Outputs CSV files containing calculated fluxes to gate_averages subfolder

### Plot calculated freshwater fluxes
- freshwater_fluxes.ipynb
- Uses output from calc_freshwater_fluxes_from_clipped_data.ipynb along with files containing ice flux data

### Scripts for sensitivity tests
- compare_fwf_density_salinity_differences.ipynb: testing sensitivity to snow salinity and snow density
- ice_density_salinity_sensitivity_testing.ipynb: testing sensitivity to sea ice salinity and density
- depth_spatial_sensitivity_test.ipynb: testing sensitivity to different snow depth quartiles
- snow_fwf_sit_sensitivity_testing.ipynb: testing sensitivity to variations in ice thickness assuming different snow depths used for ice thickness retrieval
- clip_scaled_sit_to_gates.ipynb, scale_sit_by_snow.ipynb: ancillary scripts for ice thickness sensitivity testing

### Other supplemental scripts
- snow_ice_freshwater_height_comparison.ipynb: correlations (deseasonalized) between snow freshwater height and sea ice freshwater-equivalent thickness
- examine_and_summarize_grid_cell_count.ipynb: for grid cell count across flux gates
